# خريطة المشروع

موقع **فورك العربية**: Vite + React + React Router + Tailwind.
العربية هي اللغة الأساسية وتعيش على الجذر `/`، والإنجليزية تحت `/en`.
صفحة `‎/design-system` مرجع داخلي يعرض كل الألوان والمكوّنات.

```sh
npm install     # أول مرة
npm run dev     # تشغيل محلي
npm run build   # بناء للنشر
npm run preview # تجربة ناتج البناء
```

## شجرة `src/`

```
src/
  main.tsx       نقطة التشغيل: المزوّدات + render، ولا شيء غير ذلك
  App.tsx        كل صفحات الموقع ومساراتها مكتوبة بالاسم، مرّة للعربية ومرّة لـ /en
  boot/          سكربت صغير يضبط lang وdir من الرابط قبل أول رسم للصفحة
  config/        إعدادات الموقع: المسارات، روابط القوائم، أرقام التواصل، الدومين
  data/          محتوى العميل: القطاعات التسعة والنصوص الثابتة
  pages/         مجلد لكل صفحة، باسم الصفحة
  layouts/       الهيكل الذي ترسم داخله كل صفحة: الهيدر، main، الفوتر
  components/    مكوّنات الواجهة
    navbar/      الشريط العلوي: الروابط، قائمة الخدمات، قائمة اللغة، قائمة الجوال
    footer/      الفوتر بأعمدته كلها في ملف واحد
    layout/      عناصر التخطيط: Container، Grid، Section، Stack، Divider
    ui/          العناصر الأساسية: أزرار، حقول، بادجات، أيقونات
    brand/       الشعار واللوك-أب
  lib/           كود مساعد: cn، الألوان، الترجمة i18n، usePageMeta
  styles/        index.css: كل التوكنز (ألوان، خطوط، مسافات، ظلال، نقاط الكسر)
```

## عايز تعمل كذا؟ روح لـ ...

### عايز تضيف صفحة جديدة؟

1. أضف مسارها في `src/config/paths.ts` داخل `PATHS`.
2. اعمل ملف `src/pages/<اسم-المجلد>/<Name>Page.tsx`، وابدأه بسطر
   `usePageMeta({ titleKey: 'nav.xxx', indexable: false })` — هذا يضبط عنوان
   الصفحة ووصفها. اشطب `indexable` لمّا تبقى الصفحة جاهزة لمحركات البحث.
3. أضف سطرها في `src/App.tsx` جوّا `pages`:
   `<Route path="xxx" element={<XxxPage />} />` — سطر واحد يخدم العربية والإنجليزية.
4. أضف `titleKey` ونصّه بالعربية والإنجليزية في `src/lib/i18n/translations.ts`.
5. لو الصفحة لازم تظهر في القوائم: `src/config/navigation.ts`.

### عايز تعدّل نص في صفحة؟

- نصوص الواجهة (أزرار، عناوين، أسماء القوائم): `src/lib/i18n/translations.ts` —
  نفس المفتاح موجود مرّتين، مرّة في `en` ومرّة في `ar`.
- نصوص العميل (وصف الشركة، القطاعات): `src/data/`.

### عايز تغيّر رقم تليفون أو واتساب أو إيميل؟

`src/config/contact.ts` — الرقم المكتوب (`display`) والرابط (`href`) جانب بعضهما،
فلا يتغيّر أحدهما دون الآخر. حسابات السوشيال في نفس الملف: اكتب الرابط في
`SOCIAL_NETWORKS` وسيظهر في الفوتر وحده (الرابط الفارغ لا يُنشر).

### عايز تعدّل روابط القوائم؟

`src/config/navigation.ts`: `PRIMARY_NAV` (روابط الهيدر)، `NAV_ACTIONS` (زرّا
«اطلب عرض سعر» و«احجز استشارة»)، `FOOTER_NAV` (روابط الفوتر). المسارات نفسها
تيجي من `src/config/paths.ts`، فلا تكتب رابطًا بيدك.

### عايز تعدّل محتوى قطاع؟

- الاسم والأيقونة والملخّص والترتيب: `src/data/sectorIndex.ts`.
- الخدمات والنصوص الطويلة: `src/data/sectorContent.ts`.
- القطاعات الخمسة الظاهرة في الفوتر: `FOOTER_FEATURED_SECTOR_IDS` في
  `src/data/siteCopy.ts`.
- أي نص إنجليزي كتبناه نحن مكتوب بـ `draft('عربي', 'english')` وينتظر موافقة
  العميل. بعد أي تعديل شغّل `node scripts/copy-review.mjs` ليتحدّث
  `docs/copy-review.md`. الموافقة = تحويل `draft` إلى `copy`.

### عايز تغيّر لونًا أو خطًا؟

`src/styles/index.css` داخل `@theme` — كل لون وخط ومقاس في مكان واحد، والمكوّنات
تستعمل أسماء التوكنز فقط. لا تكتب لونًا داخل مكوّن.

### عايز تغيّر الشعار؟

`src/components/brand/BrandLockup.tsx` — الشعار مرسوم بـ SVG (ليس صورة)، وفيه
الأشكال والمقاسات والاتجاه. `Logo.tsx` هو نفس الشعار داخل رابط الصفحة الرئيسية.

### عايز تنشر الموقع؟

Vercel يبني من المستودع: فرع `dev` ينشر **preview** وفرع `main` ينشر
**production**. كل إعدادات النشر في `vercel.json`، والتفاصيل في `README.md`.
قبل أي نشر: `npm run build` لازم ينجح.
